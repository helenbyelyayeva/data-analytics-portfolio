# Shipping Container Delivery Performance Analysis

## Project Overview

This project evaluates shipment delivery performance using container tracking data. The analysis focuses on delivery reliability, prediction accuracy, vessel and route performance, and monthly delivery trends.

## Business Questions

* How reliably were shipments delivered?
* How accurate were predicted delivery dates?
* Which vessels and shipping routes experienced the highest delays?
* How did delivery performance change over time?

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Key Findings

* 40.13% of shipments were delivered on or before the predicted date.
* The average delay for late shipments was 6.59 days.
* Exact delivery prediction accuracy was 17.86%.
* Average prediction error was 7.89 days.
* Delivery performance varied across vessels, routes, and months.
